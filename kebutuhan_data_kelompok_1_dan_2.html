1. Latar Belakang & Peran Sistem Kelompok 3

Berdasarkan panduan resmi pembagian modul PBL, Kelompok 3 bertanggung jawab atas mesin akreditasi utama (Core LAM INFOKOM Engine), Evaluasi Diri (LED), Laporan Kinerja Program Studi (LKPS), Pengelolaan Bukti/Evidence Terpusat, Audit Mutu Internal (SPMI), serta Dashboard Readiness & Early Warning System.

Sesuai prinsip Mata Kuliah Interoperabilitas, Kelompok 3 tidak diperkenankan melakukan redundant input (input ulang data yang sudah dikelola oleh kelompok lain). Sebaliknya, sistem Kelompok 3 wajib mengonsumsi (consume) data agregat, transaksional, dan repositori evidence dari Kelompok 1 dan Kelompok 2 melalui REST API berformat JSON.

Tujuan Dokumen: Menjadi acuan teknis bagi Kelompok 1 dan Kelompok 2 dalam merancang skema database, controller API, dan output endpoint yang akan diintegrasikan dengan modul penilaian otomatis Kelompok 3.

3 Prestasi Mahasiswa • Rekapitulasi prestasi akademik & non-akademik
• Skala prestasi: Wilayah/Lokal, Nasional, Internasional 		• Penilaian poin capaian mahasiswa pada tabel LKPS Prestasi.

3. Kebutuhan Data dari Kelompok 2 (SDM, Tri Dharma & Kerja Sama)

Data ini dibutuhkan oleh Kelompok 3 untuk penilaian otomatis pada Kriteria C3 (Relevansi Penelitian), C4 (Relevansi PkM), C5 (Akuntabilitas SDM), serta pemetaan kerja sama tridharma.

No Kategori Data Parameter / Field Spesifik yang Dibutuhkan Kegunaan di Modul Kelompok 3
1 Kualifikasi DTPS (Dosen) • Total Dosen Tetap Program Studi (DTPS)
• Jumlah Dosen berpendidikan S3 (Doktor)
• Jumlah Dosen Lektor Kepala dan Guru Besar
• Jumlah Dosen bersertifikat Serdos & Sertifikasi Profesi 		• Perhitungan skor kecukupan & kualifikasi akademik dosen.

• Jumlah mahasiswa yang dilibatkan dalam penelitian dosen 		• Pengisian otomatis Tabel LKPS Penelitian.

3 Publikasi, Sitasi & HKI • Jumlah artikel Jurnal Internasional (Scopus/WoS)
• Jumlah artikel Jurnal Nasional Terakreditasi (Sinta 1-6)
• Jumlah Buku ber-ISBN dan Sitasi karya dosen

• Kategori: Bidang Pendidikan, Penelitian, atau PkM

4. Kebutuhan Data Referensi & Master Pengguna

Kelompok 3 mengelola alur kerja pembagian borang akreditasi, penilaian reviewer, dan audit SPMI. Oleh karena itu, diperlukan referensi ID pengguna dari modul autentikasi/pengguna:

Modul di Kelompok 3 Foreign Reference yang Dibutuhkan Keterangan & Role yang Diharapkan
Mapping Tim Akreditasi mapping_tim_akreditasi.id_user ID User Dosen / Tim Penyusun yang ditugaskan mengerjakan narasi per butir indikator.
Self Assessment self_assessment.id_reviewer ID User Reviewer Internal / Asesor yang memberikan penilaian skor rubrik dan catatan evaluasi.
Audit Mutu (SPMI) data_spmi_audit.id_auditor ID User Auditor Internal yang mencatat temuan audit mutu prodi.
Validasi Bukti bukti.validated_by ID User Asesor/Pimpinan yang menyetujui atau menolak berkas bukti dukung.

6. Standar Teknis Interoperabilitas

  1. Standar Format JSON: Seluruh API wajib mengembalikan format seragam:
    { "success": true/false, "message": "string", "data": ... }.
  2. Protokol & Prefix: Menggunakan REST API standar dengan prefix versi (misal: /api/v1/...).
  3. Filter Parameter: Mendukung parameter query id_prodi dan tahun akademik (tahun).
  4. Dokumentasi: Setiap kelompok wajib menyediakan dokumentasi interaktif via Swagger / OpenAPI UI agar mempermudah pengujian timbal balik.
